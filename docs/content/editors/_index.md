Statements are `.sql` files with YAML front matter in a comment. Editors highlight the SQL on their
own; these pages cover getting them to help with the front matter too, and getting a coding agent to
write statements that generate what you meant.

- [Front matter schema](./schema/) — completion and validation for the front matter keys in IntelliJ
  IDEA and Visual Studio Code.
- [Claude skill](./claude/) — teaches [Claude Code](https://claude.com/claude-code) how statements,
  records and converters fit together.
